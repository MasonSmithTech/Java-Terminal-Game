# Java-Terminal-Game
This is a choose your own adventure style game created in java and runs entirely in the terminal.
The point of this game is to try and escape an island you are trapped on...based on the choices that you make from the prompts given to you. 
The game was created using VsCode and there is a demo hosted on google sites which says a little about the game... shows some small gameart I made, and allows you to run the code/play the game.

https://sites.google.com/view/escapeislandjavaterra/home
